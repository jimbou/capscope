CapScope: Authority Is Not a String.

A Capability-Scoped Harness for Prompt-Injection-Resistant Coding Agents

CapScope keeps tool authority in the harness, gives each coding agent only the capabilities its role needs, and checks every proposed effect at dispatch.

Dimitrios Stamatios Bouras · Yihan Dai · Sergey Mechtaev

Read paper ↓ Artifacts ↗

The CapScope principle

Text can influence a request. It cannot create authority.

Authority
Host-held capabilities
Scope
Per agent and effect
Boundary
Tool dispatch

Abstract

Indirect prompt injection turns ambient tool authority against coding agents. CapScope moves authorization into the harness: it derives a trusted task ceiling before untrusted content is read, narrows capabilities for each delegated agent, and checks every tool call against the issuing agent’s store.

Approach

Separate designation from permission.

The model may choose which action to request. CapScope decides whether that action is covered by authority already installed for that specific agent.

01

Mint

Establish a task-wide authority ceiling from trusted input and a sanitized project structure.

02

Freeze

Close the authority set before repository contents, tool output, or other injection surfaces arrive.

03

Derive

Give each delegated agent a fresh store no broader than its parent’s authority and no broader than its role.

04

Check

Authorize every proposed effect at dispatch using typed, argument-scoped capabilities held outside model context.

Evidence

300 autonomous repair runs.

The experiment holds the model, tasks, and four-agent workflow fixed while varying authorization policy and injection surface.

5

Repair tasks

Small Python projects with one defect and a failing test suite.

5

Injection surfaces

README, AGENTS.md, skill file, source comment, and tool output.

4

Policy conditions

Ambient, static global, task-specific global, and CapScope.

3

Trials per cell

Every task, surface, and authorization condition is repeated.

Headline result

CapScope executes the injected effect in 3/75 runs, versus 33/75 for the strongest global baseline. Both complete 68/75 repairs.

Trade-off: CapScope’s mean runtime is 316 seconds; its median is 208 seconds.
